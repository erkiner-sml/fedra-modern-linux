# Third-party software and data

This repository is a compatibility/installation layer. It does not relicense third-party projects.

## FEDRA

FEDRA is obtained separately by the user. This repository does not include the full FEDRA source distribution.

Published archive reference:

- FEDRA — Framework for Emulsion Data Reconstruction and Analysis
- Zenodo DOI: `10.5281/zenodo.4390588`

Check the terms attached to the exact FEDRA distribution and any files bundled with it before redistributing them.

## ROOT

ROOT is developed by the ROOT project/CERN and is obtained separately.

This repository does not redistribute ROOT binaries or ROOT source.

## Oracle Instant Client / OCCI

Oracle Instant Client is optional and is obtained separately from Oracle.

This repository does not redistribute Oracle libraries, SDK headers, ZIP/RPM packages, or other Oracle files.

## Experimental / collaboration data

Do not publish private, restricted, embargoed, or collaboration-only data merely because the software can read it.

Files such as `linked_tracks.root`, raw emulsion scans, database credentials, and reconstruction products are ignored by the included `.gitignore`.
